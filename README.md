# Dictionary App

A web application for learning English vocabulary with dictionary API integration.

## Overview

Dictionary App allows users to search for English words, view their definitions and examples, and save new vocabulary for further learning.

## Features

- Word search
- Definitions and examples
- Saved vocabulary
- Dictionary API integration
- Responsive interface

## Tech Stack

- JavaScript
- HTML5
- SCSS
- Dictionary API

## Getting Started

### Prerequisites

- A modern web browser
- Internet connection

### Installation

Clone the repository:

```bash
git clone https://github.com/Artiushchenko/Dictionary-App.git
cd Dictionary-App
```

No additional dependencies are required.

### Development

Open `index.html` in a browser or serve the project using a local development server.
